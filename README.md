# Тест «Международные финансы»

Онлайн-тест на чистом HTML/CSS/JS без сборки: случайные вопросы из `questions.txt`, таймер, мгновенная проверка, разбор ошибок и отправка результатов в Google Таблицу.

## Возможности
- 25 вопросов, 30 минут, порог сдачи 15 (настраивается в `config.json`)
- Вопросы не повторяются, пока студент не пройдёт весь банк
- Пояснения к ответам, режим тренировки, повтор только ошибок
- Поле «Группа», номера ошибочных вопросов уходят в таблицу
- Тёмная тема, адаптивный дизайн, поддержка скринридеров

## Запуск
Открывайте через http(s), иначе `fetch` не сработает:
```bash
python3 -m http.server 8000   # затем http://localhost:8000
```
Для публикации: Settings → Pages → Source: **GitHub Actions**. Деплой запускается при каждом push в `main`.

## Формат `questions.txt`
```
вопрос | вариант 1 | вариант 2 | вариант 3 | номер верного | ~пояснение (необязательно)
```
Строки с `#` игнорируются. Проверка: `python3 scripts/validate.py` (то же делает GitHub Action при каждом коммите).

## Настройка `config.json`
`title`, `questionCount`, `timeLimitMinutes`, `minCorrect`, `sheetUrl`.

## Google Таблица
1. Создайте таблицу → Расширения → Apps Script, вставьте `apps-script/Code.gs`.
2. Развертывание → Веб-приложение, доступ «Все».
3. Скопируйте URL в `sheetUrl` в `config.json`.

## Ограничение
Это статический сайт: `questions.txt` и ответы доступны любому, кто откроет файл. Для зачёта под контролем преподавателя подходит, для строгого экзамена нужен сервер, который проверяет ответы.
